# DominoSearch

Research code for comparing neural-network pruning methods, including the
original DominoSearch mixed N:M approach and uniform, structured-channel, and
unstructured-magnitude baselines.

Start with the [documentation index](docs/README.md). The latest audited
experiment is the
[ResNet-18 pruning report on Tesla T4](docs/PRUNING_EXPERIMENT_REPORT_T4.md).
